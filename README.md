# Reelbox

Расширение Chrome, которое сохраняет открытый Reels одним нажатием в папку
`Загрузки/Reels`. Личный инструмент для сбора видеореференсов.

## Установка

1. Открой `chrome://extensions`.
2. Включи «Режим разработчика» (тумблер справа сверху).
3. Нажми «Загрузить распакованное расширение» и выбери эту папку.
   Либо просто перетащи папку в окно со списком расширений.

После установки обнови уже открытые вкладки Instagram: в старые вкладки
расширение не попадает.

## Как пользоваться

Открой ролик в Instagram. Справа внизу появится круглая кнопка со стрелкой.
Нажатие сохраняет ролик в `Загрузки/Reels` с именем вида
`nike — 2026-08-01 — DKx9dQ2.mp4`.

То же самое делает иконка Reelbox в панели Chrome. Это запасной путь на
случай, если Instagram сменит вёрстку и кнопка перестанет отрисовываться.

Повторное сохранение того же ролика не создаёт дубль: расширение помнит, что
уже скачано, и говорит об этом.

## Если что-то пошло не так

**«Источник не найден»** — обнови страницу и нажми снова. Расширение читает
данные, которые Instagram присылает при загрузке ролика, и после длинной
навигации по истории их может не оказаться.

**«Не понял, какой это ролик»** — открой сам ролик, а не страницу профиля.

**Кнопки нет вообще** — проверь, что расширение включено, и обнови вкладку.
Пока не отрисовывается кнопка, работает иконка в панели.

**Ничего не помогает** — включи отладку и посмотри консоль:

```js
localStorage.reelboxDebug = '1'
```

После этого расширение печатает в консоль страницы, что именно оно нашло.
Это же нужно мне, если понадобится чинить разбор данных.

Выключается так:

```js
localStorage.removeItem('reelboxDebug')
```

## Устройство

| Файл | Роль |
|---|---|
| `src/lib/extract.js` | Чистые функции: разбор JSON, выбор качества, имя файла. Покрыт тестами |
| `src/interceptor.js` | Работает в контексте страницы, читает копии ответов Instagram |
| `src/content.js` | Кэш роликов, кнопка, определение текущего ролика |
| `src/background.js` | Загрузки, память о сохранённом, иконка в панели |
| `scripts/make-icons.py` | Перерисовка иконок, зависимостей не требует |

Ссылка на видео берётся из данных, которые страница и так получила для показа
ролика. Дополнительных запросов к Instagram расширение не делает.

Проектное решение и границы: [docs/superpowers/specs/2026-08-03-reelbox-design.md](docs/superpowers/specs/2026-08-03-reelbox-design.md).

```bash
npm test
```

## Границы

Только Reels и только по одному. Ни очереди, ни истории, ни выбора качества,
ни сторис, ни каруселей. Папка сохранения фиксирована: Chrome не разрешает
расширению писать за пределы папки загрузок.
