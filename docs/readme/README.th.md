เปิดโพสต์แล้วจะมีปุ่มกลมโผล่ขึ้นที่มุมจอ กดหนึ่งครั้ง สิ่งที่อยู่บนหน้าจอก็จะไปอยู่ในโฟลเดอร์ดาวน์โหลด เครื่องมือนี้มีเพียงเท่านี้

## การติดตั้ง

### Chrome

Chrome ไม่อนุญาตให้ติดตั้งส่วนขยายจากนอกร้านค้าของตัวเอง และร้านค้านั้นก็ไม่เผยแพร่ส่วนขยายประเภทนี้ การติดตั้งจึงต้องทำเอง

1. ดาวน์โหลด `stash-chrome-x.y.z.zip` จาก[รุ่นล่าสุด](https://github.com/antonyshakirov/stash/releases/latest) แล้วแตกไฟล์
2. เปิด `chrome://extensions` แล้วเปิดโหมดนักพัฒนา
3. กด «โหลดส่วนขยายที่แตกไฟล์แล้ว» แล้วเลือกโฟลเดอร์ที่แตกไว้

การอัปเดตก็ต้องทำเองเช่นกัน ส่วนขยายที่แตกไฟล์ไว้จะไม่อัปเดตตัวเองเลย เพราะ Chrome ไม่มีกลไกสำหรับเรื่องนี้ ให้ดาวน์โหลดรุ่นใหม่แล้วกด «โหลดใหม่» ในหน้าเดิม

### Firefox

[ติดตั้ง Stash](https://antonshakirov.com/stash/stash-latest.xpi) ด้วยการกดเพียงครั้งเดียว แพ็กเกจลงลายเซ็นโดย Mozilla จึงไม่ต้องใช้ร้านค้าและไม่ต้องเปิดโหมดนักพัฒนา ทั้งยังอัปเดตตัวเองด้วย ต้องใช้ Firefox 140 ขึ้นไป

หลังติดตั้ง ให้โหลดแท็บที่เปิดค้างไว้ใหม่ เพราะส่วนขยายเข้าไปไม่ถึง

## วิธีทำงาน

เปิดโพสต์หรือคลิปแบบเต็ม บน Instagram จะเป็นที่อยู่แบบ `/p/…` หรือ `/reel/…` ส่วนบน TikTok เป็น `/@ผู้เขียน/video/…` หรือ `/@ผู้เขียน/photo/…` ปุ่มกลมจะโผล่ที่มุมขวาล่าง และถัดไปจะมีปุ่มรูปโน้ตดนตรีเมื่อมีเสียงให้ดึง

ภาพจะถูกบันทึกทีละภาพ ถ้าเป็นภาพชุด ให้เลื่อนไปยังสไลด์ที่ต้องการแล้วกด จะได้สไลด์นั้นพอดี ต้องการสามสไลด์จากเจ็ด ก็กดสามครั้ง

ในฟีดและในตารางโปรไฟล์จงใจไม่มีปุ่ม เพราะสิ่งที่อยู่ใต้เคอร์เซอร์ตรงนั้นเป็นภาพย่อ ไฟล์ที่ได้จะแย่กว่าต้นฉบับ

เสียงถูกดึงออกจากตัวคลิปเอง และยาวเท่ากับคลิปพอดี เพลงดังสิบวินาทีในคลิป ก็ได้สิบวินาทีในไฟล์

การบันทึกภาพเดิมซ้ำจะไม่สร้างไฟล์ซ้ำ ส่วนขยายจำได้ว่ามีอะไรแล้วและจะบอกให้ทราบ ถ้ายังต้องการสำเนา ให้กดซ้ำอีกครั้งติดกัน

## ไฟล์ไปอยู่ที่ไหน

| อะไร | ที่ไหน | ตัวอย่างชื่อ |
|---|---|---|
| คลิป | `Downloads/Saved Reels` | `nike — 2026-08-01 — DKx9dQ2.mp4` |
| ภาพ | `Downloads/Saved Photos` | `nike — 2026-08-01 — DKx9dQ2 — 3.jpg` |
| เสียง | `Downloads/Saved Audio` | `nike — 2026-08-01 — DKx9dQ2.m4a` |

ตัวเลขท้ายชื่อคือลำดับสไลด์ในภาพชุด โพสต์ธรรมดาจะไม่มี

ชื่อโฟลเดอร์เปลี่ยนได้ คลิกขวาที่ไอคอน Stash บนแถบเครื่องมือแล้วเลือก «ตัวเลือก» ช่องที่เว้นว่างจะคืนค่าชื่อเริ่มต้น เครื่องหมายทับหมายถึงการซ้อนกัน `Refs/Saved Reels` จะวางโฟลเดอร์ไว้ในอีกโฟลเดอร์

## สิ่งที่ Stash ไม่ทำ

Stash ไม่ส่งคำขอไปยัง Instagram หรือ TikTok ด้วยตัวเองแม้แต่ครั้งเดียว ส่วนขยายอ่านข้อมูลที่หน้าเว็บได้รับมาอยู่แล้วเพื่อแสดงโพสต์ให้คุณ และเมื่อไม่มีข้อมูลนั้นก็จะบอกตรง ๆ แทนที่จะไปดึงมา ไม่มีอะไรถูกส่งไปที่ไหน ไฟล์เดินทางจาก CDN ของแพลตฟอร์มไปยังดิสก์ของคนที่กำลังดูโพสต์นั้นเอง

ไม่มีการข้ามลายเซ็นหรือการป้องกันใด ๆ ไม่มีการทำล็อกอินอัตโนมัติ ไม่แตะบัญชีของผู้อื่น และไม่เก็บสถิติ

ไม่มีการดาวน์โหลดภาพชุด โปรไฟล์ หรือคอลเลกชันทั้งก้อน ไม่มีคิวดาวน์โหลด และไม่มีการเลือกคุณภาพเอง เสียงถูกคัดลอกมาตามเดิม

ไม่รองรับ YouTube

## สิทธิ์และความรับผิดชอบ

Stash ไม่ได้มีส่วนเกี่ยวข้องกับ Instagram, TikTok หรือ Meta และไม่ได้รับการรับรองจากพวกเขา ชื่อเหล่านี้ปรากฏที่นี่เพียงเพื่อบอกว่าส่วนขยายทำงานที่ไหน

สิทธิ์ในสิ่งที่คุณบันทึกเป็นของผู้ที่โพสต์มัน ส่วนขยายนี้ไม่ได้ให้สิทธิ์ใด ๆ ในผลงานของผู้อื่น การบันทึกงานของคนอื่นไว้ดูและเก็บเป็นงานอ้างอิงเป็นเรื่องหนึ่ง การนำไปเผยแพร่ซ้ำหรือใช้ในเชิงพาณิชย์เป็นอีกเรื่องหนึ่ง และผู้ที่บันทึกไว้เป็นผู้รับผิดชอบ
